white +5v
black +2.5v
sync 0v

hsync 5us pulse with 64us inbetween, generated by ULA independent of CPU

vsync 400us with 16.6-20ms inbetween

- starts with IN A,FE (clamps sync to 0)
  - increment FRAME counter
  - read 8 rows of keyboard data
  - resets ULA LCNTR to 0
  - determine number of blank lines to start of live display from MARGIN = 55
  - turn NMI on with out FE,A if in slow mode, else NMI stays off
- finishes with OUT FF,A (releases sync to enable 64us hsync pulses)

Opcodes executed above 32k (A15=1) are executed by ULA which makes the CPU see a NOP (data lines low = 0 = NOP)
